## Bugs encontrados

### CRITICO

**BUG-01: Cuentas Corrientes — movimientos vacios**
- **Modulo:** cuentas-clientes.html
- **Descripcion:** Al seleccionar cliente ARTESANA (saldo $1,370,000, 2 ventas en CC), la tabla de movimientos muestra "Sin movimientos registrados"
- **Impacto:** El usuario no puede ver el detalle de debitos/creditos del cliente
- **Causa probable:** Error en la API GET /api/cuentas-clientes/:cliente_id o el cliente_id no matchea

**BUG-02: Stock Mercaderia — KG Vendidos = 0**
- **Modulo:** stock-mercaderia.html
- **Descripcion:** KPI "KG Vendidos" muestra 0 cuando ventas.html y depositos.html muestran 405 kg vendidos
- **Impacto:** Datos de stock inconsistentes con ventas reales
- **Causa probable:** La query GET /api/stock-mercaderia/kpis no contabiliza correctamente los egresos de venta, o los registros en StockMercaderia no se crearon para las ventas via POST /api/depositos/egreso

### ALTO

**BUG-03: Despalillado — Campana actual muestra "-- kg"**
- **Modulo:** despalillado.html
- **Descripcion:** KPI "Campana actual" muestra "-- kg" en vez del total despalillado
- **Impacto:** Dato de gestion no disponible
- **Causa probable:** Query de totales no retorna resultado o campo null

**BUG-04: Despalillado — Header muestra "Cargando..."**
- **Modulo:** despalillado.html
- **Descripcion:** El banner superior muestra "Cargando..." en lugar del nombre de la temporada
- **Impacto:** Visual, no funcional
- **Causa probable:** La llamada a /api/temporadas/activa no resuelve a tiempo o falla

**BUG-05: Ventas KPI incluye venta anulada**
- **Modulo:** ventas.html
- **Descripcion:** KPI "405 KG Vendidos" y "$2,003,000 Total Ingresos" incluyen la venta anulada R-0001 (200 kg, $1,000,000). Grid totals correctamente excluye y muestra 205 kg / $1,003,000
- **Impacto:** KPIs de ventas sobreestimados
- **Causa probable:** Query de KPIs no filtra estado='anulada' en MovimientosDeposito

### MEDIO

**BUG-07: Saldo de caja anomalo**
