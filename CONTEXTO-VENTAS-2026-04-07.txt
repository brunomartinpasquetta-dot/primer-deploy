1. FLUJO DE VENTA
================================================================================

1. Frontend (ventas.html) selecciona:
   - Cliente (opcional, para CC)
   - Temporada (obligatorio)
   - Forma de pago (obligatorio)
   - Items: categoria -> subcategoria -> kg -> precio/kg

2. Backend: POST /api/depositos/egreso
   - Validacion: stock suficiente
   - Asignacion FIFO: resuelve sub-lotes automaticamente
   - Transaccion SQL:
     - INSERT Remitos (genera numero automatico)
     - INSERT MovimientosDeposito (para cada sub-lote)
     - INSERT RemitoItems
     - INSERT StockMercaderia
     - UPDATE LotesMercaderia (etapa: vendido_parcial/vendido)
     - IF forma_pago = CC:
         INSERT CuentaCorrienteClientes (debito)
       ELSE:
         INSERT Caja (ingreso)
   - Response: OK + remito_id + numero_remito

3. Visualizacion en:
   - remitos.html: lista de remitos, cambio de estado
   - cuentas-clientes.html: saldo del cliente
   - stock-mercaderia.html: historial y auditoria

5. TIPOS DE MOVIMIENTO EN StockMercaderia
================================================================================

tipo = 'ingreso'              — Fruta que entra (cosecha -> deposito)
tipo = 'egreso_venta'         — Venta a cliente
tipo = 'egreso_despalillado'  — Sale para despalillar
tipo = 'egreso_descarte'      — Descarte
tipo = 'ingreso_anulacion'    — Reversa un egreso (anulacion)
tipo = 'egreso_anulacion'     — Reversa un ingreso (anulacion)

================================================================================
6. CARACTERISTICAS ESPECIALES
================================================================================

- Asignacion automatica FIFO: sub-lotes asignados por orden de entrada
- Transacciones atomicas: toda venta es transaccion SQL completa
- Saldo acumulado CC: window function SQL (SUM OVER ORDER BY)
- Deteccion CC automatica: verifica forma_pago.es_cuenta_corriente
- Historial paralelo: sincronizacion StockMercaderia + MovimientosDeposito
- Auditoria completa: usuario, fecha, movimientos, anulacion
- Embalaje retornable: cajones con saldo pendiente de devolucion
- Cotizaciones integradas en stock-mercaderia.html
