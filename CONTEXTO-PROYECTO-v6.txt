CONTEXTO DEL NEGOCIO
---------------------
Sistema ERP genérico para gestión de cosecha agrícola.
Nombre: CosechaApp — Gestión de Cultivos
Nicho: Productores pequeños y medianos argentinos sin sistema de gestión
Aplica a: frutilla, soja, trigo, arándanos, vid, zapallitos, cualquier cultivo
Usuarios: productores, encargados de campo, operarios
Dispositivos: celular en campo + PC en oficina/galpón

-----------------

Logo: public/img/logo-icon.png
Paleta: verde oscuro #2D5016 primario, dorado #F5A623 acento, crema #F7F3EE fondo
Tipografía: DM Sans + JetBrains Mono (datos)

STACK TECNOLÓGICO
------------------
- Servidor: Node.js v24 + Express (puerto 3000)
- Base de datos: SQL Server (Docker, puerto 1433)
- WebSocket: balanza RS232 (librería ws)
- Frontend: HTML + JS vanilla + cosecha.css
- Entorno desarrollo: Mac con VS Code + Claude Code

------------------------
1. Abrir Docker Desktop
2. cd ~/cosecha-app && node server/index.js
3. Abrir http://localhost:3000

REGLAS DE CAMPAÑA
------------------
- Solo UNA campaña activa a la vez
- Al activar una campaña se desactiva la actual automáticamente
- TODOS los módulos precargan la temporada activa automáticamente en sus selectores
- Patrón: fetch('/api/temporadas/activa') → setear select → disparar evento change

LÓGICA DE NEGOCIO — REGLAS INAMOVIBLES
----------------------------------------
1. VENTA → INGRESO en Caja + EGRESO en MovimientosDeposito + EGRESO en StockMercaderia
2. DESCARTE → EGRESO en MovimientosDeposito (tipo='egreso_descarte') — NO mueve Caja
3. COMPRA efectivo → EGRESO automático en Caja dentro de la misma transacción
4. COMPRA CC → débito en CuentaCorrienteProveedores
5. INGRESO depósito → INSERT MovimientosDeposito + UPDATE StockMercaderia
6. JUNTADA → destino obligatorio: 'deposito' o 'descarte'
   - Suma de kilos asignados debe == kilos cosechados (tolerancia ±0.01)
   - Cosechero obligatorio antes de registrar
   - Permite destino mixto: parte depósito + parte descarte en una sola transacción

BALANCE: cosechado = en depósito + vendido + descartado
