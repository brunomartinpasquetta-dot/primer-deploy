## RESTRICCIONES GIT — OBLIGATORIAS EN TODA TAREA

- NO ejecutar `git add`, `git commit` ni `git push` sin autorización explícita del usuario.
- Sugerir mensaje de commit + lista de archivos a commitear.
- El usuario ejecuta manualmente o dice "comitea" / "hacé el commit" / "ok commit".
- Esta restricción prevalece sobre cualquier memoria de autonomía persistente.
- Si un prompt de tarea incluye "NO ejecutar git commit", esa instrucción es absoluta
  e inamovible durante toda la tarea, incluso si el usuario aprueba cambios individuales.
  Solo un mensaje explícito del usuario pidiendo el commit la overridea.
